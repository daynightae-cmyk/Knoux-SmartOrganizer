# أتمتة KNOuX SmartOrganizer

## النطاق المسموح

الأتمتة جزء محلي محدد من تطبيق Windows، وليست منفذ أوامر أو خدمة AI أو schedule عام. يسمح المخزن فقط بالأدوات التالية:

| المعرّف | النوع |
|---|---|
| `smart-scan` | قراءة فقط |
| `disk-overview` | قراءة فقط |
| `downloads-inventory` | قراءة فقط |
| `temp-cleanup-preview` | قراءة فقط؛ لا ينفذ حجر أو حذف |
| `system-health` | قراءة فقط |

تدعم الجداول daily وweekly وmonthly وstartup. تسمى مهام Windows باسم `KNOuXSmartOrganizer-<uuid>`، وتستخدم executable الحالي مع معرف داخلي ثابت فقط.

## ما لا تسمح به الأتمتة

لا يمكنها جدولة إصلاحات النظام أو تغيير الخدمات أو تعطيل عناصر بدء التشغيل أو تطبيق تنظيف أو تنظيم ملفات أو shell أو PowerShell أو أمر يحدده المستخدم. يرفض مخطط الإدخال معرف tool أو trigger أو label غير صالح.

## إدارة جدول

ينشئ المستخدم الجدول من مركز الأتمتة، ويمكنه إيقافه واستئنافه وتشغيله الآن أو حذفه. ينفذ `run now` الأداة allowlisted نفسها ويسجل النتيجة محلياً. عند الحذف، يزيل التطبيق مهمة KNOuX التي يملكها فقط ولا يمس مهام Task Scheduler أخرى.

## التخزين والاستمرارية

يحفظ التطبيق metadata في `automations.json` داخل userData. مزيل التثبيت لا يمحو userData افتراضياً، لذلك تبقى metadata مقصودة. يجب مراجعة الجداول المملوكة بعد أي ترقية أو إعادة تثبيت. يثبت `smoke:reinstall` بقاء مخزن الأتمتة المعزول وإمكانية قراءة التطبيق المعاد تثبيته له؛ لا توجد نتيجة ترقية بين نسختين منشورتين بعد لغياب artifact سابق.

## الأمان

لا تبدأ مهمة مجدولة نافذة تفاعلية: تستخدم `--automation-run=<uuid>` وتتحقق العملية الرئيسية من وجود الجدول وتمكينه قبل تشغيل allowlisted tool. يبقى التطبيق التفاعلي ذا مثيل واحد، بينما يسمح هذا التنفيذ الرأسـي المحدود بمهمة مجدولة مستقلة.
