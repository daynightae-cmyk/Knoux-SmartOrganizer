# سياسة بيانات إزالة التثبيت

## السياسة الافتراضية

يفصل KNOuX SmartOrganizer بين ملفات التطبيق وبيانات المستخدم. إعداد NSIS الحالي يستخدم `deleteAppDataOnUninstall: false`. لذلك يزيل مزيل التثبيت ملفات البرنامج والاختصارات ومزيل التثبيت نفسه، **ولا يحذف بيانات المستخدم المحلية بصمت**.

| الفئة | السياسة الافتراضية عند الإزالة |
|---|---|
| ملفات التطبيق في مجلد التثبيت | تُزال. |
| اختصارات Start/Desktop | تُزال. |
| metadata إزالة التطبيق | تُزال وفق NSIS. |
| `settings.json` ونسخته الاحتياطية | تبقى. |
| `history.json` والسجلات | تبقى. |
| `automations.json` | يبقى؛ لا يزيل التطبيق مهاماً غير مملوكة. |
| حجر التنظيف وسجلات التراجع | تبقى، حتى لا تضيع القدرة على الاستعادة تلقائياً. |
| تقارير أو exports اختار المستخدم مسارها | تبقى في مسار المستخدم. |

## لماذا تبقى البيانات

يمنع هذا التصميم فقدان إعدادات أو تاريخ أو ملفات محجورة قابلة للاستعادة عند إزالة التطبيق أو إعادة تثبيته. يثبت `smoke:reinstall` أن بيانات مستخدم معزولة تبقى بعد الإزالة وتقرأها الحزمة المعاد تثبيتها.

## إزالة البيانات يدوياً

إذا أراد المستخدم إزالة بيانات KNOuX نهائياً، يغلق التطبيق أولاً ويراجع الحجر وسجلات التراجع، ثم يحذف مجلد userData الخاص بالتطبيق يدوياً فقط عندما لا يعود بحاجة إلى الاستعادة. لا تحذف الحجر قبل التأكد من عدم وجود ملف تريد استعادته.

## مهام Task Scheduler

تدار مهام KNOuX باسم `KNOuXSmartOrganizer-<uuid>`. مزيل التثبيت لا ينفذ مسحاً عاماً لـ Task Scheduler، ولا يلمس مهاماً غير مملوكة. راجع المهام المملوكة قبل حذف userData كي لا تبقى task تشير إلى تطبيق لم يعد مثبتاً.
