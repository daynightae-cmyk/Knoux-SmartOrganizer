# خصوصية KNOuX SmartOrganizer

## الملخص

KNOuX SmartOrganizer تطبيق **محلي أولاً**. لا يتطلب تشغيل الوظائف الأساسية حساباً أو خادماً أو نموذج AI أو CDN أو خط remote font. القياس عن بعد وتحليلات الاستخدام وتقارير الأعطال معطلة في مخطط الإعدادات ولا يرسل التطبيق تقارير استخدام بصمت.

## البيانات المحلية

| نوع البيانات | الاستخدام | الموقع التقريبي | سياسة الإزالة الافتراضية |
|---|---|---|---|
| الإعدادات | اللغة والمظهر وسياسات السلامة | Electron userData | تبقى بعد إزالة التطبيق. |
| سجل العمليات | النتائج والنجاح/الفشل ومدة العملية | `history.json` | يبقى بعد إزالة التطبيق. |
| سجلات التدقيق | أحداث التطبيق المنقحة | `logs/operations.ndjson` مع أرشيفات محدودة | تبقى بعد إزالة التطبيق. |
| بيانات الأتمتة | جداول KNOuX metadata وسجل التشغيل | `automations.json` | تبقى بعد إزالة التطبيق؛ لا يلمس التطبيق مهاماً غير مملوكة. |
| الحجر وسجلات التراجع | استعادة التنظيف والتنظيم | بيانات KNOuX المحلية | تبقى حتى يتم التعامل معها صراحة. |
| exports | الإعدادات والسجل والتشخيصات | مسار يختاره المستخدم | يملك المستخدم الملف الناتج. |

## السجلات والتنقيح

يدور سجل العمليات عند حد حجمه ويحتفظ بعدد محدود من الأرشيفات. تُنقح مفاتيح مثل `password` و`token` و`secret` و`authorization` و`cookie` قبل الكتابة في سجل التدقيق. يعرض تصدير التشخيصات معلومات نسخة التطبيق ونظام التشغيل وقدرات الأدوات والإخفاقات الحديثة بعد تنقيح المسارات المحلية ومحتويات الملفات الخاصة.

لا يضمن التنقيح إخفاء كل معرفة بالسياق؛ راجع أي export قبل مشاركته، ولا تشارك سجلاً يحوي مسارات أو معلومات محلية لا تريد كشفها.

## الشبكة والتحديثات

لا توجد آلية تحديث مدمجة أو تنزيل تلقائي في هذا الإصدار. لا يفترض فتح التطبيق اتصالاً إلى طرف ثالث. أدوات تشخيص الشبكة تقرأ إعدادات Windows المحلية؛ لا تنفذ فحص منافذ هجومي أو اتصالاً خارجياً. يثبت دخان offline تشغيل الحزمة مع حظر شبكة Chromium.

## التحكم

يمكن للمستخدم تعطيل logging التشخيصي في الإعدادات، تصدير الإعدادات والسجل، أو إزالة بيانات التطبيق يدوياً بعد مراجعة [سياسة بيانات الإزالة](UNINSTALL_DATA_POLICY.md). لا يقدم مزيل التثبيت خياراً خفياً يمحو بيانات المستخدم.
