# دليل مستخدم KNOuX SmartOrganizer

## المبدأ الأساسي

تعرض الواجهة نتائج محلية من Windows ولا تصنع درجات أو نتائج أو نجاحات. عند اختيار أداة، راجع الوصف وحالة التوفر قبل تشغيلها. الأدوات التي تعدّل بيانات أو إعدادات محلية تطلب تأكيداً صريحاً وتعرض سجل تراجع عندما يكون متاحاً.

## الفحص والتخزين والملفات

تقرأ **صحة النظام** و**الفحص الذكي** حالة الجهاز دون تعديل. تعرض أدوات التخزين الملفات الكبيرة والتكرارات بعد تحقق SHA-256 والمجلدات الفارغة. لا تحذف أدوات القراءة الملفات.

استخدم **تنظيم التنزيلات** أولاً في وضع المعاينة. عند قبول النقل، يسجل التطبيق journal محلياً يتيح أداة التراجع إعادة الملفات المنقولة إذا بقيت وجهاتها قابلة للوصول.

## التنظيف القابل للاستعادة

تعرض معاينة التنظيف الملفات المؤقتة المؤهلة وفق عمر الملف وإعدادات التنظيف. عند تطبيقه، تُنقل الملفات إلى حجر KNOuX داخل بيانات التطبيق بدلاً من الحذف الدائم. استخدم **تراجع عن التنظيف** مع معرّف journal لاستعادتها. لا تشغّل التنظيف على ملفات لا يمكن تقييمها أو لا تخصك.

## بدء التشغيل والأتمتة

جرد بدء التشغيل قراءة فقط. التعطيل مقيد بقيمة محددة للمستخدم الحالي ويحتاج تأكيداً؛ الاستعادة تستخدم journal محلياً وترفض استبدال قيمة موجودة.

تنشئ الأتمتة مهام Windows Task Scheduler فقط لأدوات قراءة allowlisted: الفحص الذكي، نظرة الأقراص، جرد التنزيلات، معاينة التنظيف، وصحة النظام. لا تستطيع الأتمتة تشغيل إصلاح أو خدمة أو أمر عام. راجع [دليل الأتمتة](AUTOMATION.md).

## الخدمات والإصلاح

تعرض صفحة الخدمات الجرد وتمنع الخدمات المحمية. أي تغيير service أو repair يتطلب العملية المدرجة فقط، والتأكيد، وامتيازاً منفصلاً عند الحاجة. لا تشغّل العمليات الإدارية إذا لم تفهم أثرها؛ يستخدم الاختبار الآلي dry-run ولا يمثل نصيحة لإجراء إصلاح حي.

## الإعدادات والسجل والتشخيصات

تُحفظ الإعدادات محلياً ويمكن تصديرها أو استيراد JSON صالح أو إعادة ضبط قسم محدد. يعرض السجل النتائج الفعلية ويمكن تصديره بصيغة JSON أو CSV. تصدير التشخيصات ينشئ JSON محلياً منقحاً يتضمن النسخة، حالة التوقيع، قدرات الأدوات، وإخفاقات حديثة منقحة؛ لا يتضمن محتويات ملفات خاصة أو أسراراً.

## عدم الاتصال

تعمل الوظائف المحلية الأساسية من دون اتصال. لا يوجد في هذا الإصدار زر تحديث مزخرف أو تنزيل تحديث تلقائي؛ معلومات الإصدار فقط هي المتاحة حتى تُنفذ آلية تحديث حقيقية ومتحققة.
