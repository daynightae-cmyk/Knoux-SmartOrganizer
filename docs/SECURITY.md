# أمان KNOuX SmartOrganizer

## حد العمليات

يعمل التطبيق بثلاثة حدود منفصلة:

| الحد | المسؤولية | ما لا يستطيع فعله |
|---|---|---|
| React renderer | العرض، إدخال المستخدم، عرض النتائج | لا يملك Node.js أو shell أو PowerShell أو filesystem أو تنفيذ أوامر. |
| preload | دوال IPC مسماة ومثبتة | لا يقبل channel أو command ديناميكياً. |
| Electron main | التحقق، المحركات المحلية، التخزين، dialogs | لا ينفذ مدخل renderer كبرنامج أو script عام. |

تستخدم النافذة `contextIsolation: true` و`sandbox: true` و`webSecurity: true` و`nodeIntegration: false`. لا يوجد `remote` أو جسر تشغيل أوامر عام.

## الأدوات والبيانات

يسجل كل tool في سجل واحد بمخطط إدخال Zod صارم ومخرج منظم ومسبار قدرة. المتصفح يرى حالة توافر آمنة فقط، ولا يرى executable أو argument array أو مسارات `System32` أو script أو command من منفذ الامتيازات.

## العمليات الإدارية

الإصلاحات مقيدة بمعرّف عملية ثابت ومواصفات مجمدة عميقاً. لا يقبل privileged runner حقولاً مثل `executable` أو `args` أو `command` أو `shell` أو `script` أو `path`. أدوات الخدمة مقيدة باسم خدمة مطابق ومجموعة actions ثابتة وقائمة حماية. لا يرفع التطبيق كله؛ يتم طلب elevation لكل عملية فعلية تستدعيه.

## عمليات الكتابة الآمنة

عمليات التنظيم والتنظيف وبدء التشغيل مصممة بسجلات تراجع. تنظيف الملفات ينقل إلى حجر داخل بيانات التطبيق ولا ينفذ حذفاً دائماً. يخضع تعطيل بدء التشغيل لقيمة HKCU صريحة وjournal استعادة. لا تختبر CI عمليات إصلاح أو خدمة حية.

## الأسرار والتوقيع

لا يحتوي المستودع شهادة أو مفتاحاً خاصاً. تفحص بوابة الإصدار ملفات `.pfx/.p12/.pem/.key` ومؤشرات المفاتيح الخاصة وبيانات اعتماد التوقيع المضمنة. تعتمد بيانات توقيع الشفرة على بيئة البناء أو أسرار CI فقط؛ راجع [CODE_SIGNING.md](CODE_SIGNING.md).

## التدقيق والاختبارات

تشمل الاختبارات السلبية رفض حقول الحقن، عمليات غير معروفة، خدمات غير مسموحة، أوامر مجدولة غير مسموحة، ومدخلات تخالف المخططات. تسلسل writes الذرية وإعادة المحاولة المحدودة لقفل Windows يمنعان تعليقاً غير محدود في الإعدادات وسجل العمليات.

يمكن للباحثين الإبلاغ عن مشكلة أمنية مع وصف قابل لإعادة الإنتاج، الإصدار، وسجل تشخيصات منقح. لا ترفق أسراراً أو محتوى ملفات شخصية أو شهادة توقيع.
