# تثبيت KNOuX SmartOrganizer

## المتطلبات

يدعم هذا الإصدار Windows x64 فقط. يجب استخدام المثبّت `KNOuX-SmartOrganizer-Setup-x64.exe` الذي يطابق بصمة SHA-256 المنشورة في مانيفست الإصدار. لا يدّعي المشروع توافقاً مثبتاً مع بيئات لم تجر عليها اختبارات موثقة.

## التثبيت التفاعلي

شغّل المثبّت واختر مسار التثبيت عند الحاجة. يتضمن NSIS اختصار قائمة Start واختصار سطح المكتب ومزيل تثبيت. لا يُفترض ظهور امتيازات إدارية غير مبررة، لأن التثبيت الافتراضي لكل مستخدم ولا يرفع التطبيق كاملاً.

بعد التثبيت، افتح **KNOuX SmartOrganizer** وتحقق من ظهور اللغة والواجهة. الأدوات المحلية الأساسية تعمل دون اتصال بالإنترنت. إن أظهر Windows تحذيراً عن الناشر أو SmartScreen، راجع [حالة التوقيع](CODE_SIGNING.md): قد تكون القطعة مرشح توزيع غير موقع عندما لا تتوفر شهادة موثوقة.

## التثبيت الصامت

يمكن تنفيذ تثبيت NSIS غير تفاعلي لمسار اختبار مملوك:

```powershell
KNOuX-SmartOrganizer-Setup-x64.exe /S /D=C:\KNOuX-Test
```

تتحقق اختبارات المشروع من exit code ووجود الملف التنفيذي وتشغيل الحزمة المثبتة ثم إلغاء التثبيت. لا تستخدم مساراً يحتوي بيانات منتج حية في سيناريوهات الاختبار الآلي.

## الإزالة وإعادة التثبيت

يمكن تشغيل مزيل التثبيت من Windows أو بصمت:

```powershell
& 'C:\KNOuX-Test\Uninstall KNOuX SmartOrganizer.exe' /S
```

يزيل مزيل التثبيت ملفات البرنامج والاختصارات وملف الإزالة. **لا يحذف بيانات المستخدم المحلية افتراضياً**؛ يبقى هذا متسقاً مع `deleteAppDataOnUninstall: false` كي لا تضيع الإعدادات والسجل وحجر التنظيف وسجلات التراجع بلا اختيار صريح.

يثبت `npm run smoke:reinstall` سيناريو معزولاً: تثبيت، إنشاء بيانات محلية من التطبيق، إزالة صامتة، تحقق من بقاء البيانات، إعادة تثبيت، ثم تشغيل التطبيق المعاد تثبيته. الاختبار لا يمس بيانات مطور أو مستخدم حقيقية.

## الترقية

لا يوجد إصدار سابق منشور في هذا المستودع وقت إعداد هذا الدليل؛ لذلك لا توجد نتيجة ترقية نسخة سابقة يمكن تسميتها PASS. الإعدادات تمتلك سلسلة ترحيل `v1 → v2`، لكن قبول ترقية مثبّت بين قطعتين منشورتين يظل متطلباً عند توفر artifact سابق موثوق. راجع [التحقق من الإصدار](RELEASE_VERIFICATION.md).
