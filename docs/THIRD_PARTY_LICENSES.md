# سجل تراخيص المكونات

هذا السجل يغطي الاعتمادات المباشرة ووقت تشغيل سطح المكتب الظاهر في `package.json` وقت تدقيق الإصدار. استُخرجت بيانات الترخيص والمصدر من npm registry في 2026-08-24؛ يجب إعادة تدقيقها عند ترقية الاعتمادات.

| المكوّن | النسخة المقفلة/المستخدمة | الترخيص | المصدر |
|---|---:|---|---|
| KNOuX SmartOrganizer | 0.4.0 | MIT | هذا المستودع |
| React | 18.3.1 | MIT | https://github.com/react/react |
| React DOM | 18.3.1 | MIT | https://github.com/react/react |
| Zod | 3.23.8 | MIT | https://github.com/colinhacks/zod |
| lucide-react | 0.462.0 | ISC | https://github.com/lucide-icons/lucide |
| @vitejs/plugin-react-swc | 3.5.0 | MIT | https://github.com/vitejs/vite-plugin-react |
| Electron | 43.4.1 | MIT | https://github.com/electron/electron |
| electron-builder | 26.15.3 | MIT | https://github.com/electron-userland/electron-builder |

Electron وelectron-builder أدوات بناء/تشغيل يحتاجهما توزيع سطح المكتب؛ لا يعني إدراجهما أن المنتج ينقل ملكية Windows أو مكونات النظام. تبقى التراخيص العابرة للاعتماد محل تدقيق إضافي عند إدخال native module أو SDK جديد.

لا تظهر في هذه القائمة أي تبعية مباشرة بترخيص غير معروف وفق بيانات registry التي جُمعت. لا تحل هذه الوثيقة محل مراجعة قانونية متخصصة لقنوات توزيع تجارية أو دمج مكونات جديدة.
