# Applications — KNOuX Software Command

## Direction contract

THESIS: An installed-software register that reads as one continuous ledger of the machine's programs, with a coverage header that states what KNOuX actually knows and a staging tray that appears only when the user has queued work. It refuses the incumbent catalog arrangement (tool list left, runner panel right) and refuses a card grid of identical program tiles.

OWN-WORLD: Midnight graphite ground (#08090f / #111320 / #171a2a), KNOuX violet as the brand constant, Applications' own secondary semantic tint teal, hairline rules between ledger rows, real Windows icons as the only permitted imagery, tabular figures for version and size columns, fine directional light on the selected band, elevated charcoal for the tray. No nested cards, no gradient text, no decorative glow on data.

STORY: A non-technical owner arrives, sees how many programs are installed, how much of that inventory is measured versus estimated, types a name or picks a facet, reads one row, opens its dossier in place, and can queue several programs for review. Every control names its consequence; anything without a backend says so instead of pretending.

FIRST VIEWPORT: Header line carries the world name and live counts (programs, machine-wide vs user, packaged vs desktop) with a segmented coverage ribbon under it (icons, size, date, publisher known — hatched where unknown). Then the command strip: search, facet chips with counts, sort, view mode. Then the ledger at full width with real icons, dense rows, publisher grouping, and the focused program's dossier band expanded inline. A staging tray pins to the bottom only once a selection exists.

FORM: Fused surface composition — The Live Register as the spine (ranked 3, seed key 6ccc1081, mode operate) raised by The Staging Deck (selection queue + tray) and The Coverage Ribbon (measured data-truth header). Owner chose the fusion explicitly.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
